# Lab 1 – Microsoft 365 License Administration

## Overview

In this lab, I assigned and managed a Microsoft 365 Business Premium license using the Microsoft 365 Admin Center.

This lab demonstrates one of the fundamental responsibilities of a Microsoft 365 Administrator by ensuring users receive the appropriate Microsoft 365 license and cloud services required for their role.

---

# Objectives

The objectives of this lab were:

* Assign a Microsoft 365 Business Premium license
* Verify the license assignment
* Review the included Microsoft 365 service plans
* Understand Microsoft 365 licensing and service provisioning

# Service Plans

The Microsoft 365 Business Premium license provides access to multiple Microsoft cloud services, including:

* Microsoft Exchange Online
* Microsoft Teams
* SharePoint Online
* OneDrive for Business
* Microsoft Intune
* Microsoft Defender for Business
* Microsoft Entra ID
* Microsoft 365 Apps

The assigned license was successfully verified, and the available service plans were reviewed.

---

# Why License Management is Important

Microsoft 365 Administrators use license management to:

* Grant users access to Microsoft 365 services
* Control feature availability
* Manage subscription usage
* Ensure users receive the correct cloud services based on business requirements
