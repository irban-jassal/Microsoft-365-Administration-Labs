# Lab 8 - Microsoft 365 Reports & Service Health Administration

## Overview

In this lab, I explored Microsoft 365 monitoring and reporting capabilities using the Microsoft 365 Admin Center. The lab demonstrates tenant reporting, service health monitoring, Microsoft update tracking, and organization-level configuration review.

---

## Tasks Completed

### 1. Reviewed Microsoft 365 Usage Reports

Accessed Microsoft 365 usage reports to review tenant activity and service usage.

Reviewed reporting capabilities for Microsoft 365 workloads including:

- Microsoft Teams
- SharePoint Online
- OneDrive
- Exchange Online

Usage reports help administrators monitor user adoption, service activity, and license utilization.

### 2. Reviewed Service Health Dashboard

Accessed the Service Health dashboard to monitor Microsoft 365 service availability.

Reviewed:

- Current service status
- Service incidents
- Service advisories
- Microsoft cloud service availability

Service Health helps administrators identify whether issues are caused by Microsoft services or tenant configuration.

### 3. Reviewed Message Center

Accessed Message Center to review Microsoft 365 announcements and upcoming changes.

Reviewed:

- Security improvements
- Required administrator actions

Message Center helps administrators prepare for changes and communicate updates to users.
